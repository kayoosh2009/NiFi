## Структура объекта:

```
object button{
	id: play_button;
	style: main;
	layer: false;
	
	location{
		up: 50%;
		down: 50%;
		right: 50%;
		left: 50%;
	}
}
```

    object - обозначение объекта
    button - вид объекта
    id - спецаильное id для обращения с бекэндом
	style - стиль обьекта ( привязка к стилю )
    layer - наложение на объект ( false - нельзя \ true - можно)
    location - место нахождения объекта

## Объект 001: text

```
object text{
	id: null;
	layer: false;
	
	text{
	"Hello world!"
	}
}
```

Просто текстовый объект который создан для отображения текста.
В поле text{} вводится текст который нужен для отображения внутри кавычек, если нужно распечатать специальный символ тогда используйте обратный слэш и символ.

Если нужно обратиться к тексту и добавить отображение параметра то обращаемся к text и даем переменную и пишем вот такой текст

```
object text{
	id: theWonNum;
	layer: false;
	
	text{
	"The number: {number} won!"
	}
}
```

### Как параметр попадает в текст

Объект и код связываются по `id`. В примере выше `id: theWonNum`,
а в тексте стоит `{number}`.

Бэкенд передаёт значение так: `set("theWonNum", "number", 42)`
- `theWonNum` - id объекта
- `number` - имя параметра в фигурных скобках
- `42` - значение (число, строка, true/false или пусто)

Если параметр ещё не передан или равен null, на его месте ничего не показывается.
Чтобы напечатать `{`, используйте `\{`.

Вот небольшой пример кода)
```
set(&mut params, "theWonNum", "number", Value::Int(42));
```
