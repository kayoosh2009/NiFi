Существует несколько видов объектов, у каждого свои особенности и возможности, каждый объект особенный по особенному и нужен для разных задач.
Так же список объектов будет пополняться в этом файле...

---
## Структура объекта:

```
object button{
	id: play_button;
	style: main;
	layer: false;
	
	location{
		up: 50%;
		down: 50%;
		right: 50%;
		left: 50%;
	}
}
```

    object - обозначение объекта
    button - вид объекта
    id - спецаильное id для обращения с бекэндом
	style - стиль обьекта ( привязка к стилю )
    layer - наложение на объект ( false - нельзя \ true - можно)
    location - место нахождения объекта

---

## Объект 001: text

```
object text{
	id: null;
	layer: false;
	
	text{
	"Hello world!"
	}
}
```

Просто текстовый объект который создан для отображения текста.
В поле text{} вводится текст который нужен для отображения внутри кавычек, если нужно распечатать специальный символ тогда используйте /" ( слеш + символ )

---

## Объект 002: backend-text

```
object backend-text{
	id: num;
	layer: false;
	
	text{
	"The win number is: " + (num) + "!"
	}
}
```

Специальный текстовый объект который умеет отображать элемент который приходит с backend, предположим если нужно отобразить результат чего либо или запроса, правила те же как и у text но в этот раз нужно закрывать двойные ковычки и при помощи плюсов и скобок призывать обьект который отправляется по id элемента.
